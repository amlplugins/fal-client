# @amlplugins/fal-client

Native `@fal-ai/client` SDK re-exported under the `@amlplugins` namespace.

> Fal.ai Client — serverless generative-AI gateway (image, video, audio, 3D) with subscribe/run/queue APIs.

## Install

```bash
npm install @amlplugins/fal-client
```

## Use

```ts
import { /* named exports from @fal-ai/client */ } from "@amlplugins/fal-client";
// or
import sdk from "@amlplugins/fal-client";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
